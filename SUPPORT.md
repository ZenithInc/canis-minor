# Support

Canis Minor is community-supported software.

- Read the [documentation](https://zenithinc.github.io/canis-minor/) and [troubleshooting guide](https://zenithinc.github.io/canis-minor/operations/troubleshooting/).
- Ask usage and deployment questions in [GitHub Discussions](https://github.com/ZenithInc/canis-minor/discussions).
- Use an Issue Form for reproducible bugs or scoped feature proposals.
- Follow [SECURITY.md](SECURITY.md) for private vulnerability reports.

When asking for help, include the Canis Minor version, Ubuntu release, architecture, relevant redacted configuration, exact commands, logs, and observed versus expected behavior. Remove PSKs, public infrastructure addresses, SSH targets, usernames, and host keys.

Only Ubuntu 24.04 x86_64 with IPv4 is currently supported. Windows, ICMP, IPv6, and container-namespace forwarding questions may be closed or redirected according to the [roadmap](ROADMAP.md).
