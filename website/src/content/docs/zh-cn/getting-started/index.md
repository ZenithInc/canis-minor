title: 安装概览

Canis Minor 0.1 支持 Ubuntu 24.04、Linux x86_64 和 IPv4。典型部署由一台公网或以其他方式可达的服务端，以及一台需要通过该服务端出站的客户端主机组成。

:::caution
客户端会修改 nftables 与策略路由状态。首次部署时保留独立 SSH 会话和云平台控制台，不要首先在无法带外恢复的主机上测试。
:::

## 选择安装方式

- [使用 Release](./releases/)：获得 GitHub 工作流来源证明、校验和与静态 musl 二进制。
- [从源码构建](./source/)：适合审计或修改实现。

0.1 不提供容器镜像、操作系统软件源或 crates.io 包。

## 前置条件

服务端需要一个可达 TCP 端口（默认 5260）。客户端需要：

- 支持 IPv4 TPROXY 的 Ubuntu 24.04 x86_64 内核。
- `nft`、`ip` 与 systemd。
- root 或等效的 `CAP_NET_ADMIN`/`CAP_NET_RAW` 权限。
- 可用于断线直连的正常网络连接。
- 使用仓库部署脚本时需要 SSH 密钥认证。

两端必须持有相同的 32 字节原始 PSK，文件权限为 `0600`。该密钥是 0.1 中唯一的认证秘密。

## 部署顺序

1. 构建或下载两个静态二进制并完成验证。
2. 使用显式服务端地址生成 PSK 与配置。
3. 启动服务端并在防火墙中允许其 TCP 监听端口。
4. 保持客户端的独立管理连接。
5. 安装并启动客户端。
6. 执行[验收流程](../project/acceptance/)，包括隧道中断恢复。

完整运维流程见[部署与升级](../operations/deployment/)。
